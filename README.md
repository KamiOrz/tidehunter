# Tidehunter

**English** · [简体中文](README.zh-CN.md)

**[Play online](https://kamiorz.github.io/tidehunter/)** · [Source code](https://github.com/KamiOrz/tidehunter)

A first-person underwater spearfishing game for the browser. Swim through kelp forests and rock canyons, hunt procedural fish, and keep an eye on your oxygen—and the sharks.

Tidehunter builds on the beautiful procedural ocean in [Abyssal Garden](https://github.com/Noniv/abyssal-garden) by **Maksymilian Dendura**. It adds fish behavior, projectile combat, health and oxygen, scoring, and animated first-person equipment. The original MIT copyright and license are preserved.

![The procedural underwater world](.github/screenshots/whale-fluke.jpg)

## Play

1. Open **[Tidehunter](https://kamiorz.github.io/tidehunter/)** in a browser with **WebGPU** support. Current desktop Chrome or Edge is recommended.
2. Wait while the underwater world is generated on your device.
3. Select **Start diving** and start swimming. Sound starts after you interact with the game.

No account, installation, or backend is required. For offline play, download [`index.html`](index.html) and open it in a compatible browser. The game and its artwork are embedded in that single file, currently about **2.2 MiB**.

WebGPU needs a secure browser context: the public HTTPS site, `localhost`, or a supported local file. To serve your checkout locally, run this from the repository root:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). If WebGPU is unavailable, try an updated Chrome or Edge with hardware acceleration enabled.

## Languages

The game supports **English** and **Simplified Chinese**. Use **English / 中文** in the menu to switch without restarting your dive.

On a first visit, Chinese browser languages select Chinese; other browser languages select English. A manual selection is remembered between visits. You can also open a language-specific link:

- [Play in English](https://kamiorz.github.io/tidehunter/?lang=en)
- [以中文游玩](https://kamiorz.github.io/tidehunter/?lang=zh)

## Controls

| Action | Keyboard and mouse |
|---|---|
| Look around | Move the mouse after entering the scene |
| Swim | `W` `A` `S` `D` |
| Descend / ascend | `Q` / `E` |
| Swim faster | Hold `Shift` |
| Fire a spear | Left mouse button or `Space`; hold to keep firing |
| Pause / open menu | `Esc` or the `≡` button |
| Mute / unmute | `M` |
| Show performance statistics | `H` |
| Jump to another viewpoint | `1`–`6` |
| Restart after a dive ends | `R` or the retry button |
| Change detail level | **Low / Medium / High** in the menu; reloads the page |

**Touchscreen:** hold a finger on the scene to swim forward, slide to steer, and add a second finger to swim faster. Use the on-screen fire button to shoot. The game uses landscape orientation, including a rotated layout on portrait screens. Touch support is experimental.

## How to play

- The speargun automatically reloads in **0.8 seconds** and has unlimited spears. The trigger and finger move locally, the rubber bands recoil, and the weapon has a reload indicator and sound.
- Spears travel from the visible muzzle at **38 metres per second**. Lead moving targets; the seabed and rock walls block shots.
- A hit leaves a spear attached to the fish as it swims and turns. Larger fish need more hits. A killed fish keeps its spears while rolling and sinking for about **7 seconds**; spears stuck in rock remain for about **12 seconds**.
- Fish flee when startled or hit. Two predator types can approach and attack the diver.
- Catch **8 fish per round** to earn **500 bonus points**, refill oxygen, and restore up to **25 health**.
- A full oxygen supply lasts about **3 minutes** underwater. Swim to within **4 metres of the surface** to refill it. Running out of oxygen drains health.
- When health reaches zero, the dive ends. Restart to try again.

There are **12 fish species** with randomized proportions and distributions. The active fish pool is capped at **240 / 156 / 96** on High / Medium / Low detail. Fish replenish in navigable water around the player; restarting a dive retains the current session's random seed.

The seabed, cliffs, arches, and tunnels have collision. Decorative plants, the ship, the whale-tail sculpture, and loose props can be swum through.

## What is procedural?

The terrain, underwater scenery, fish meshes and patterns, flying spears, and sounds are generated by code. Rendering uses **WebGPU directly**, without a game engine or 3D library, and audio is synthesized with the **Web Audio API**.

The first-person hands and speargun use **AI-generated photographic-style artwork**, embedded as a transparent PNG. It is a 2D foreground viewmodel with local finger, trigger, and band deformation, not a rotatable 3D asset. Projectile movement, fish, collision, and spear attachments are simulated in 3D. See [artwork provenance and the generation prompt](source/assets/README.md).

Detail settings reduce scene complexity. Dynamic resolution and draw distance adapt to frame cost, and the browser remembers the selected quality settings. Performance depends on your device; lowering detail can help with loading and rendering pressure.

## Build and develop

Use **Node.js 18 or newer**:

```bash
cd source
npm ci
npm test
npm run build
```

`npm run build` writes the minified, self-contained `index.html` in the repository root. No build step or asset download is needed to play that file.

| Command, from `source/` | Output |
|---|---|
| `npm test` | Gameplay and language-support tests |
| `npm run build` | Production `../index.html` |
| `npm run build:readable` | Unminified `../index.html` for debugging |
| `npm run build:dev` | Separate, unminified `../dev.html` with development tools |

In `dev.html`, `F` starts a one-minute camera flight and `B` runs it as a benchmark, reporting frame and GPU timing when timestamp queries are available. Gameplay is suspended during the flight. These shortcuts are not part of the production game.

## Publish with GitHub Pages

This repository publishes the **`main` branch / repository root** to [kamiorz.github.io/tidehunter](https://kamiorz.github.io/tidehunter/). The root [`.nojekyll`](.nojekyll) file keeps the output as ordinary static files.

After changing the source:

1. Run the tests and `npm run build` in `source/`.
2. Commit the source changes **and the generated root `index.html`**.
3. Push to `main` and wait for GitHub Pages deployment to finish.

All runtime artwork is embedded in the generated HTML, so deployment does not depend on absolute asset paths or a particular repository name.
